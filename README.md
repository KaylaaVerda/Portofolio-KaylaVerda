# Portofolio Kayla Verda (Verda)

Website portofolio pribadi Kayla Verda Fawnia Heses (Verda), mahasiswa S1 Teknik Informatika Universitas Dian Nuswantoro (Udinus) Semarang yang berfokus pada desain visual antarmuka dan pengembangan front-end web.

## Teknologi Utama
- Next.js (App Router) dengan TypeScript
- Tailwind CSS (Palet bakery lembut)
- Framer Motion (Animasi halus dengan preferensi reduced motion)
- Google Fonts (Great Vibes dan Lora via next/font)
